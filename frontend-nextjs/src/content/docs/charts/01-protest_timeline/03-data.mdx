Most of the data for our **Protest Timeline Chart** comes from the [Armed Conflict Location & Event Data Project (ACLED)](https://acleddata.com/), which compiles protest data around the world. Access to ACLED data is governed by its license.

ACLED has given permission for Media Impact Monitor to display organising groups and protest sizes. The dashboard publishes daily totals for each organising-group combination, not individual ACLED records. Co-organised protests contribute once to each timeline total; organisation statistics include protests involving that organisation, so adding organisation totals can double-count shared protests.

ACLED descriptions, locations, event types, raw size text and individual-event identifiers are excluded from public API responses. Descriptions may be processed privately to classify topics; this does not make them available to dashboard users. Public summaries are projected after cached data is retrieved, including older cache entries.

Size estimates are derived from reported crowd sizes. Unknown sizes are counted separately; reported totals do not impute missing participants. These are estimates of participation across protests, not counts of unique people.

## Data limitations

- Sometimes, ACLED can miss a protest
